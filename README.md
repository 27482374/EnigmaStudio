# Enigma Studio

Site officiel d'Enigma Studio.

## Direction artistique

Thème tropical contemporain : crème, jungle, lagon, mangue et hibiscus.
Le site est volontairement en français et pensé comme un véritable site de studio indépendant.

## Fichiers

- `index.html` — structure et contenu
- `styles.css` — direction artistique et responsive
- `main.js` — animations et interactions

Les commentaires dans les fichiers expliquent les grandes parties du code.
