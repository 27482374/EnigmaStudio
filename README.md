# Enigma Studio

Site vitrine officiel d'Enigma Studio.

## Direction artistique

Le site mélange une base éditoriale de studio indépendant avec une identité tropicale :
- crème / papier chaud
- vert végétal
- orange corail
- jaune soleil
- aqua
- typographies DM Sans + Fraunces
- formes organiques et illustrations créées uniquement en CSS

L'objectif est d'avoir une identité reconnaissable sans dépendre d'un template ou d'une banque d'images.

## Structure

- `index.html` — contenu et structure
- `styles.css` — toute la direction visuelle
- `main.js` — animations et interactions

## Inspiration

La structure générale reprend l'idée d'un petit studio indépendant qui présente simplement ses jeux, son équipe et sa façon de travailler. La direction artistique, les textes et les visuels sont propres à Enigma Studio.

## Lancer le site

Ouvrir `index.html` directement dans un navigateur ou utiliser GitHub Pages.
