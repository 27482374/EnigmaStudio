# ENIGMA STUDIO

Independent game studio website.

## Structure

- `index.html` — complete page structure and content
- `styles.css` — visual identity, layout, responsive design and animations
- `main.js` — cursor, magnetic interactions, reveals and navigation
- `assets/` — future images, logos, game media and other assets

## Visual direction

Enigma uses an editorial / experimental direction:

- Ivory paper
- Graphite
- Mineral green
- Copper accent
- Serif display typography
- Monospace technical details
- Custom cursor
- Abstract visual language
- Large editorial typography
- Motion used as part of the identity

## Local preview

Open `index.html` in a browser.

For a better development workflow, use a local server such as VS Code Live Server.
